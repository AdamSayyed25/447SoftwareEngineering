## 6. Key Decisions Made

### Technical Decisions
1. **Frontend Technology**: Selected React with Vite for fast development
2. **State Management**: Chose React Context API for simpler state management
3. **Data Storage**: Using localStorage for Sprint 1 prototype
4. **Styling Approach**: CSS3 with black & gold UMBC branding

### Process Decisions
1. **Agile Framework**: Scrum with 2-week sprints
2. **Tools**: JIRA for tracking, GitHub for version control
3. **Communication**: MS Teams for daily collaboration
4. **Review Cycle**: Sprint review and retrospective after each sprint

### Strategic Decisions
1. **Delivery Model**: Campus-based delivery without GPS requirement
2. **Worker Model**: Student delivery workers
3. **Payment Strategy**: Simulated payment system for prototype
4. **Security Approach**: Privacy-first design with data protection
